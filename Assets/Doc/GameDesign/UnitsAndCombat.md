# 单位逻辑与战斗合同

版本：0.1 · 2026-09-22 · 本稿为待实现行为；数值见 [Balance.md](Balance.md)。

## 1. 入门只需理解三种职责

| 兵种 | 玩家容易理解的职责 | Demo操作要求 | 不增加的能力 |
| --- | --- | --- | --- |
| 工人 Worker | 采金、伐木、建造 | 开局已自动工作；需要时右键资源或点地块建造 | 不战斗、不狩猎、不维修 |
| 战士 Warrior | 靠近敌人持续近战，承受更多伤害 | 与弓手一起框选前进即可 | 无冲刺、嘲讽、手动举盾、群体斩击 |
| 弓手 Archer | 在战士后方射击 | 自动保持攻击距离，玩家只决定前进或撤回 | 无边走边射、爆炸箭、无限自动风筝 |
| 长枪兵 Lancer（完成版） | 在前排后侧刺击，也更适合协助拆建筑 | 自动完成普通攻击 | 无额外反骑兵系统、冲锋、击退、手动架枪 |
| 修士 Monk（完成版） | 自动治疗受伤的友军 | 随军行动，无需点治疗技能 | 无法术攻击、复活、召唤、魔法值管理 |

Demo的预算算例采用8名战士、6名弓手、6名工人；这不是固定编制，也不表示工人最多6名。20人口可以自由分配：例如10工人+10军人、4工人+16军人、暂时全工人发展或无工人的全军进攻。所有兵种均无单独数量配额，选择的经济和战斗代价由玩家承担。

不建立“某种武器必须克制某种不存在的兵”的系统。战士与弓手的区别主要来自血量、射程、近身通行和造价；长枪兵靠触及距离及建筑伤害系数形成用途，修士以少一名输出换取续航。

## 2. 命令优先级

优先顺序为：死亡/淘汰 → 最近一条玩家命令 → 当前攻击或工作阶段 → 自动索敌。自动行为不能覆盖玩家的直接移动和回城命令。

| 命令 | 怎么开始 | 自动行为与结束条件 |
| --- | --- | --- |
| 前进交战 | 军队右键地面、按钮或A | 朝目的地移动，途中发现可攻击敌人则交战；目标结束后继续原目的地，到达后转待命 |
| 集中攻击 | 右键敌军/敌建筑 | 以此目标为优先，追到有效射程后攻击；目标死亡、失效或不可达则结束，转当前地点待命 |
| 直接移动 | “移动/撤退”按钮或M后点地面 | 沿途不自动停下攻击；到达后待命，适合绕行或局部后撤 |
| 回城休整 | 军队右键己方城堡；任意单位“回城”按钮 | 沿途不接敌；抵达后不自动攻击或治疗，满血仍保持休整，不恢复旧路线；新命令才结束。受伤只重置恢复等待时间 |
| 停止 | 停止按钮或S | 取消当前指令并锚定当前位置；恢复有限范围的待命自卫，不继续原路线 |
| 驻守（进阶） | H | 保持位置，只攻击当前射程内敌人，不为了攻击而移动 |
| 采集/施工 | 工人右键资源/地块或点击建造 | 循环完成工作，结束和失效处理见规则文档；不参加军队自动索敌 |

连续点击时最后一条命令生效，不累计隐藏指令队列。相同输入在联机的统一命令顺序下执行；不能让不同客户端各自决定谁先占地块、扣钱或出生。

## 3. 索敌、追击与脱战

军队每隔固定扫描间隔寻找视野内、关系为敌对、活着且可达的候选。Demo全图可见不等于无限索敌：仍使用本地索敌半径。完成版若启用迷雾，则同时要求当前可见。

自动选择先考虑攻击范围内的敌方战斗单位，再考虑索敌半径内最近的敌方战斗单位；没有这些目标才考虑工人，最后考虑建筑。相同优先级比较实际平面距离，距离相同按稳定实体编号决定。显式集中攻击不受自动目标优先级影响。

选中目标后保持目标，不因旁边出现另一名残血敌人而反复切换。目标死亡、关系改变、失去有效可见性、超出追击界限或确认不可达才释放。不会把视野外的旧坐标当作可实时追踪的敌人。

- 待命单位以待命点为锚，只允许有限距离的自卫追击；达到上限返回锚点，避免被一名敌人拖到全图另一端。
- 前进交战以本次发现敌人的位置为临时锚；超过追击上限就放弃，继续原路线。到达原目的地才建立新的待命点。
- 显式集中攻击可在地图内追逐可见目标，不受自动追击锚限制；玩家下达新命令立即取代它。目标不可达时必须中止并提示，不能永远锁死。
- 卡住后在限定时间内重试少量次数；确认失败则短暂跳过这个自动目标，避免每次扫描又锁回同一堵墙后的单位。失败后停止在最后可达点，不瞬移。
- 所有单位都不自动撤退、自动绕敌后或自动决定攻击另一座基地。自动化承担重复动作，进退仍由玩家决定。

## 4. 普通攻击与动画

### 4.1 统一结算

普通攻击对**一个锁定敌人**结算，无友军伤害、随机闪避、暴击和范围溅射。当前原型的近战框内群伤不直接沿用。每段近战命中时再次检查目标存活、敌对、距离与地形遮挡；命中失败就落空，不把伤害转移给旁边另一个人。

攻击周期从起手开始计时，前摇和动作时长包含在周期内，不额外把动画长度再加一次。技能伤害以统一游戏时间驱动，表现动画只表现结果，不能由两台机器各自的动画事件决定伤害。

战士继续使用已有两段挥砍动画，每段造成总伤害的一半。每段只结算一次；同一段持续碰到目标不能每帧重复扣血。长枪兵一次刺击结算一次。两者攻击时原地站定，不滑行攻击。

玩家的直接移动/回城/停止命令可以立即取消尚未结算的攻击段或尚未发箭的前摇；已经发生的伤害不撤销，已经启动的攻击周期也不重置。禁止通过反复点击移动取消后摇来突破表定攻击频率。死亡立即取消后续未发生的近战命中。

弓手正常射击时先站定，在释放时检查目标合法性和射程，发射已有箭矢；玩家撤退命令可提前取消这次未释放的射击并立即移动。已射出的箭使用释放时保存的伤害，之后升级不会改写它。命中原目标时再次检查存活和敌我关系；目标已死亡则箭消失，不自动跳到旁边单位。射手死亡或被淘汰不撤销已经射出的箭，因此允许同一逻辑步互相击杀。

为降低首版复杂度，箭矢只跟随其锁定目标、不被路过单位拦截、不因目标正常走位随机脱靶；它是有飞行时间的定向单体攻击，不是物理抛射解算。释放前需要直线不穿越地形实体阻挡；释放后的跟随箭不再次进行地形碰撞。该简化必须全端一致，不能出现一端被墙挡、一端命中的分歧。

### 4.2 距离与通行

所有射程以攻击者与目标的**逻辑占地边缘间距**计，不以精灵图屋顶、武器贴图长度或中心距离混算。角色暂按统一身体半径处理；建筑为固定矩形占地。城堡防御射程与弓手射程遵循同一边缘间距口径，避免弓手从城堡射程外无伤拆城。

近战在可攻击位置停下，冷却期间不继续钻进敌人体内。弓手进入射程就停，目标靠近时仍攻击而不自动无限后退；撤退交给玩家。远程攻击和治疗不能穿过不可通行的实体墙体进行起手，但友军士兵不遮挡。

军队必须有基础位置分离：敌方身体不能被穿过，友军不能永久叠成一个点；点击地面为多个单位分配附近有效落点。通路太窄时排队、局部绕行，失败会报告卡住。首版不做可切换阵型、推挤冲撞和复杂自动包抄。

这项需求尚未由当前项目满足。当前单位身体相互忽略碰撞，不能据此宣称战士已经能挡住敌人。完成这个最小通行规则后再验证“前排掩护后排”，不能只调血量来掩盖互相穿身的问题。

## 5. 各单位的特殊处理

### 工人

工人没有普通攻击。受到攻击时显示受袭提示并继续当前工作，玩家可以一键选中闲置/受袭工人；回城或直接移动命令不会被采集循环覆盖。建造完优先回先前资源点，资源失效再在原区域找同类目标。工人右键己方城堡/仓库表示“先交付携带资源，然后在附近待命”，无携带时直接待命，不恢复旧采集任务；显式点击“回城”按钮则交付后保持休整，直到新命令。

为避免一名幸存工人也没有、又缺钱而空等：当没有活工人、没有工人在训练且金币不足工人造价时，城堡显示“紧急招工”，免费训练一名工人，每玩家每局一次，仍需人口空位和训练时间。它不是自动送钱，不产生可取消退款，也不能反复触发。人口满时可继续依靠现有军队作战，按钮说明阻塞原因。城堡已毁时不可使用。

### 战士

Demo只自动近战，不启用现有Guard技能。举盾素材保留；不以已有字段就承诺已经具有减伤。取消主动盾防可让新手只关注队形与进退，避免同时管理攻击和姿态按钮。

### 长枪兵（完成版）

使用现有方向刺击，按目标方向选择动画并左右翻转。更长触及距离让它可以站在战士附近或后侧参与攻击，建筑伤害较战士更高；血量低于战士，不代替前排。Defence仅保留为未来表现库存，本版无隐藏架枪增伤、被动反伤或额外姿态。

### 修士（完成版）

默认自动治疗范围内受伤的己方/友方军人，排除自己、工人、建筑、已死亡或满血单位。优先最低生命比例，其次最近距离，再按稳定编号；可以治疗其他修士，同一单位可以接受多名修士的治疗。

施法起手后站定，达到释放点再确认目标合法且仍在治疗范围。目标消失或满血则这次治疗落空，仍消耗本轮施法周期，不能反复取消来提高治疗频率。移动命令可立即取消尚未释放的治疗。没有魔法值；每名修士占1人口，玩家可自由决定数量，持续治疗以周期、射程和减少军队输出人数的代价平衡。

前进交战时修士跟随所选军队的后部有效落点，途中只有在治疗范围内出现目标才停下施法，不为了追一名伤员离开队伍超过自动追击范围。单独右键地面是普通移动；右键敌人不会跑上去攻击，停在其当前治疗射程外的可达位置并提示“无攻击能力”。右键友军可把它设为优先照顾对象，仍不突破范围与周期。

## 6. 死亡与可读性

生命归零立即停止命令、工作、占位和技能，释放人口；随后移除角色并在脚底播放已有烟尘。烟尘独立播放，不计人口、不接收命令。没有死尸复活和残血倒地阶段。

同一单位只结算一次死亡；同一步多人攻击造成的超额伤害不产生额外收益。治疗不能挽回本步已判定死亡的单位；同一步内先结算攻击与死亡，再对仍存活的目标结算治疗，避免全端顺序不一致。

血条只在选中、受伤或战斗时明显显示，健康未选中单位弱化；每位玩家使用已存在颜色，选中轮廓和血条还需区分自己、队友、敌人。受击闪色短促，烟尘不叠成长期遮挡；不为每次普通攻击增加巨大特效。动画和脚底轮廓保持可辨，比堆叠技能图标更重要。

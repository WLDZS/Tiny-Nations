城堡和塔的攻击只针对敌方可控单位，不攻击建筑、无友伤、单体箭矢。城堡每2秒10伤，射程6.5；塔每2秒16伤，射程6.5。索敌半径等于射程；优先射程内最近的敌方军人，其次工人，锁定后保持直到死亡或离开射程。城堡与塔不能由玩家手动点杀，也不因第15分钟而提高自身伤害。起手0.35秒发箭，周期从起手算，使用同一Arrow资源。

军备升级：150G+100W，60秒，城堡研究一次；战斗单位最大生命×1.15、造成伤害×1.10。普通攻击与建筑攻击系数相乘，治疗量和建筑防御箭不升级。研究后战士最大HP276、弓手172.5；存活者当前HP不增加。生命/伤害允许0.1精度累计，最终伤害只在全部乘法完成后四舍五入到0.1，不逐层取整；UI显示向上取整的当前生命，死亡以真实累计值≤0判断。

“最多一座兵营/靶场”包含已预约施工的地块、在建与完成状态；被摧毁或取消后可以在原地重建。所有生产队列3格、人口预占、退款及施工生命规则见[规则文档](RulesAndFlow.md)。

工人的理论持续收入：

`每分钟收入 = 60 × 携带量 / (携带量÷工作速度 + 2×单程距离÷移速 + 交付时间)`

- 安全区：`60×12/(12+8/2.4+1)=44.08资源/分钟/人`。
- 没有仓库的外区（单程12格）：`60×12/(12+24/2.4+1)=31.30资源/分钟/人`。
- 4金2木的6工人：理论176.33G和88.16W/分钟。外区建仓库后，回到约4格路程，每工人约恢复12.78资源/分钟效率，但必须承担100资源的建仓库投资和被袭风险。

这是连续平均值；实际每包交付、施工占用、走位、等待工作位和转场均降低收入。安全金矿在4金工人持续采集的理想状态约6.8分钟耗尽，木材在2木工人下约9.1分钟耗尽；真实因开局发展和施工通常更晚，目标引导8–12分钟向外转移。没有到点强行关矿的时间规则。

## 5. 一个可负担的开局与满编预算

开局可以立即安排2名补充工人（100G），借1名伐木工建兵营（80G100W），余60G100W；人口为存活6+预占2=8/10。两名新工人去金矿，施工者完工返回木材，达到4金2木。

随后建靶场、两栋住宅，再逐步形成8战士6弓手6工人的20人口；住宅须在下一次入队会超过容量前建成。初始两名战士免费，因此实际新增军人为6战士6弓手。

| 投资 | G | W |
| --- | ---: | ---: |
| 新增6战士 | 420 | 120 |
| 新增6弓手 | 420 | 240 |
| 新增2工人 | 100 | 0 |
| 兵营+靶场 | 160 | 200 |
| 两住宅 | 0 | 120 |
| 总投入 | 1100 | 680 |
| 减初始库存后需采集 | 860 | 480 |

这张表不包括仓库、研究、伤亡和重新建造。施工合计占一名工人100秒；按两名新工人在20/40秒加入、施工主要占用伐木工估计，金币约5:08、木材约6:17才累计满足全部预算，最后训练约6:37–6:39完成。此为累计预算下界近似，不是经离散命令/资源交付验证的精确开局脚本；若队列顺序、地块路程或包裹交付推迟，则成军更晚。实际首轮目标为6–10分钟形成主要军队。

以下只是4金2木、零库存、两生产建筑均存在的稳态补员估计，更多工人可提高收入，但会挤占军队人口，且同一资源点工作位有限：

| 补员 | 成本G/W | 攒够资源时间下界 | 加最后一个训练时间的近似 |
| --- | --- | --- | --- |
| 1战士 | 70/20 | 23.8秒 | 43.8秒 |
| 1弓手 | 70/40 | 27.2秒 | 49.2秒 |
| 4战士2弓手 | 420/160 | 约2:23 | 约2:45 |
| 全部8战士6弓手 | 980/400 | 约5:33 | 约5:55 |

批量项允许边采边训；若同一生产建筑串行队列成为瓶颈还会更慢。已有足够预备金时，单名只需20/22秒，不能把“攒钱时间”当成固定训练间隔。全灭代价仍明显高于撤回休整，但一次损失几名不必立刻认输。

## 6. 伤害与攻城的静态复核

不含升级、走位和漏击：战士DPS=`16/1.5=10.67`；弓手=`14/1.8=7.78`；长枪兵=`20/1.8=11.11`；单名修士治疗速度上限=`24/3=8HP/秒`，N名的理论上限为`8N HP/秒`，仍需站定且有可治疗目标。修士数量不限，完成版必须测试大量治疗兵混编能否导致僵局；优先调整治疗周期/治疗量，不通过强制固定配兵掩盖问题。

以每个单位第一次实际命中为0时刻，忽略弓箭飞行时间：

| 单挑/集火 | 需要命中 | 击杀时间 |
| --- | --- | --- |
| 战士→240HP战士 | 30次8伤，即15轮双击 | 21.38秒（两段相隔0.38秒） |
| 战士→150HP弓手 | 19次8伤，第10轮第一段 | 13.5秒 |
| 弓手→240HP战士 | 18箭 | 30.6秒 |
| 弓手→150HP弓手 | 11箭 | 18秒 |
| 4弓手→240HP战士 | 5轮齐射 | 7.2秒 |
| 8弓手→240HP战士 | 3轮齐射 | 3.6秒 |

实际从下令到死亡还要加接敌、首次前摇和弹道时间。整队集火可以很快杀人；自动索敌保持目标、单体命中、队伍展开和回城按钮共同降低新手操作负担，不靠承诺每个士兵都能逃走。

攻城静态模型：`总DPS=战士人数×10.6667×0.4 + 弓手人数×7.7778×0.2`；`拆城秒数=4000/总DPS`。假设所有人能持续命中，不计城堡反击、守军、走位和升级，真实通常更慢。

| 攻城军队 | 15分钟前 | 决战×1.5后 |
| --- | ---: | ---: |
| 4战士6弓手 | 151.5秒 | 101.0秒 |
| 6战士6弓手 | 114.5秒 | 76.3秒 |
| 8战士6弓手 | 92.0秒 | 61.3秒 |

城堡仅有5DPS自动防御是刻意选择：用于压制早期极少量偷城，但不使无人防守的城堡足以消灭一支赢下团战的残军。塔暂不进入Demo，避免早期双重防御火力拖慢收尾。城堡HP、建筑伤害系数和决战系数应一起观察，不能分别无限加高。

## 7. 调整顺序

先检查实际收支、拥挤/卡路和操作理解，再调数值。每轮只改一组主要变量，并保存对局记录：

1. 新手3分钟仍不会出兵：先改提示和交互，不降低全部价格掩盖教学问题。
2. 4分钟大多已满20人口：降低采集或提高兵价；不要把人口上限抬高。
3. 10分钟多数仍不足10名军人：先查木材收入、住宅提示和施工工人是否归岗，再小幅调整造价。
4. 正常团战经常小于5秒：检查是否仍有群伤/叠人/多次命中；确认后才考虑降低攻击或提高血量。
5. 平均15分钟前结束：区分失误速攻与势均力敌对局，再调整城堡耐久或补员；不添加强制无敌。
6. 多数依赖20分钟强制结算：先调整决战系数或建筑耐久，不增加新兵种、新资源和更多人口。
7. 修士造成打不死：先降治疗量/增加周期；不为反制再发明禁疗兵和新特效。

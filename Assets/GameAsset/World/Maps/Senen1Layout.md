# Senen1 首图布局

## 场景范围

- 场景：`Assets/GameAsset/Scene/Senen1.unity`，逻辑范围 `x=0..95`、`y=0..63`，每格为 1 世界单位。
- 布局预览：`Senen1Preview.png`。它来自生成数据，不是 Unity 实际渲染截图。
- 全图按 `(x,y) → (95-x,63-y)` 作 180° 旋转对称。`Grid/Water` 是最底层，在 96×64 全部格子铺水；`Grid/Ground` 只在岛屿陆地铺草。四条地图边缘和四角的露出水面相互连通，弯曲海岸包围一座岛；露出水面的格子写入 `Collision`。
- 地形、建筑、树木和矿点沿用项目现有的 64 PPU 像素素材。

## 双人对战布局

| 区域 | 位置与用途 |
| --- | --- |
| 蓝方基地 | 城堡视觉锚点 `(12,32)`，4×4 占格 `x10..13,y30..33`；单位出生标记 `(17.5,32.5)`。 |
| 红方基地 | 城堡视觉锚点 `(83,31)`，4×4 占格 `x82..85,y30..33`；单位出生标记 `(78.5,31.5)`。 |
| 中路 | `x14..81,y28..35`，视觉路面宽 8 格；中央 `x39..56,y25..38` 保留至少 18×14 的无障碍交战区。 |
| 上下侧路 | 沿岛的南北侧绕行，路面宽约 5 格；内陆湖与海岸共同构成可辨识的侧翼。 |
| 转线口 | 两处内陆湖在 `x37..42`、`x53..58` 留通道，可在中路与上下侧路之间转线。 |
| 外部扩张 | 西北 `(31,56)`、西南 `(31,7)`、东南 `(64,7)`、东北 `(64,56)` 各有一处金矿、四棵可采树和一块 2×2 仓库地块。 |

浅褐色 `Decoration` Tilemap 显示路线与建造地块，部队也可走其他无障碍草地。`Water` 排在 `Ground` 下方，不给水层加碰撞；通行由 `Ground` 和 `Collision` Tilemap 决定。露出的水面、资源物、城堡、建造地块及部分装饰植被占格；装饰石块不占格。

双方各预留兵营、靶场各 1 块 3×3，住宅 2 块 2×2，修道院 1 块 3×3，塔 1 块 2×2；四处外矿各预留仓库 2×2。场景 `WorldObjects/MapMarkers` 有对应命名标记。这些地块暂为地图占位，正式建造与生产仍需玩法系统接入。

## 资源美术

全图有 8 处金矿、32 棵可采树：每方安全区为 2 矿与 8 树，四处扩张区各为 1 矿与 4 树。另有 48 棵静态装饰树、36 株灌木和 24 块装饰石。资源分布与道路、海岸保持旋转对称。

已逐张检查项目中的 `GoldStone1..6`、`GoldResource`、`Tree1..4`、`WoodResource` 和 `Bush1..4`。矿点使用四种矿体造型，且每个 Sprite 与对应 Animator Controller 同时覆盖，避免静态动画把变体恢复为 `GoldStone1`：

| 对称矿点 | 矿体外观 |
| --- | --- |
| 蓝安全矿 01 / 红安全矿 01 | `GoldStone3` |
| 蓝安全矿 02 / 红安全矿 02 | `GoldStone4` |
| 西北 / 东南外矿 | `GoldStone5` |
| 西南 / 东北外矿 | `GoldStone6` |

可采树与装饰树轮用 `Tree1..4`，灌木轮用 `Bush1..4`，同一对称位置使用同种外观。`GoldStone1/2` 是尺寸较小的矿体，`GoldResource` 与 `WoodResource` 是搬运资源图，暂不作地图矿点或树木。素材外观不决定储量；安全矿 600G、外矿 800G、安全树和外部树各 100W 仍为策划值，当前 Prefab 尚未配置采集容量。

## 制作与验收

`Tools/GenerateSenen1.py` 根据 `Demo` 的场景结构和项目现有素材生成此场景、预览图及对象引用。脚本检查 96×64 范围、海面覆盖边缘、旋转对称、中央开阔区和主要目标的静态可达性。`Senen1` 目前是独立场景；`DemoState` 仍加载 `Demo`。Unity 中还需查看实际地形接缝、不同矿与树的动画显示、物件遮挡和单位走位。
